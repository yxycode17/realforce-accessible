REALFORCE 无障碍助手 0.1.0 / 开发者：yxycode17

运行 release\RealforceAccessible.exe。无需安装 NVDA 插件。
依赖本机原软件目录中的 RFSWLib.dll 和键盘布局文件；暂时不要卸载原软件。
本版只适配 R3HB11，以及已检查的 REALFORCE 4.1.1.0 库。
原库升级后会停止连接，避免未经检查的协议变化。

使用顺序
1. 保存并退出原 REALFORCE Software 和 CONNECT。
2. 打开助手，若只找到一台支持的键盘，会自动读取当前配置；多台时选择设备后按 F5 读取。
3. Ctrl+1：设备状态。摘要文本可以通过方向键逐行阅读、选择和复制。
4. Ctrl+2：逐键设置。搜索实体按键，例如 Caps、Ctrl、F1；Tab 进入按键列表，方向键选择，Enter 编辑。
   编辑对话框分别列出 A 普通、A Fn、B 普通、B Fn 四层映射，以及两套逐键 APC。
   主窗口中的详细信息文本还会列出按上次读取的当前配置（或尚未提交的助手编辑值）计算的 APC。
5. Ctrl+3：自定义快捷键。方向键选择槽位，Enter 编辑；用复选框选择左右 Ctrl、Shift、Alt、Win，用组合框选择主键。
   “组合预览”可以读出完整快捷键。无需实际按出可能被系统或 NVDA 截获的组合键。
   定义好快捷键槽位后，还需在“逐键设置”中把目标实体按键映射为对应的“自定义快捷键 N”。
6. “设备状态”分区的“设备设置：名称 / APC / ECO / A/B 方案”可以设置键盘名称、全键 APC、逐键配置 1/2、当前键盘方案 A/B、ECO 模式和自定义 ECO。
   键盘名称最多 32 个英文、数字或半角符号。
   颜色/亮度自定义暂不开放：原库将 R3HB11 标为 Hybrid，keyboardSupport_LedCcustom 为 false，原版对应面板按此标志隐藏。
   已对照原版运行界面：LED Color / Brightness 面板被隐藏，但仍暴露在无障碍树中。旧版读出的红色/75%只是通用字段，不能作为此型号实际灯光状态。
   ECO 自定义里的指示灯开关为独立设置，继续保留。
   修改逐键 APC 配置不会自动启用该配置；需要把 APC 模式切到对应逐键配置。
7. 对话框中的“暂存修改”只修改助手内存，不发送到键盘。
8. 查看“改动清单”，点击“保存到键盘”，核对确认后才进行实际写入。
9. “放弃修改”只恢复本次读取的快照；F5 会重新向键盘读取。
10. Ctrl+4：按键统计。摘要显示读取时间和实体键次数总计，Tab 到列表后用方向键浏览。
    默认按次数从高到低排列，相同次数按实体键编号排列；包含零次按键。在统计页按 F5 后保持在统计页。
    普通层和 Fn 层不拆开计数；数据来自键盘，不是助手运行期间的键盘监听。
    “清零按键统计”需确认后立即执行，不等待保存配置；不能撤销。清零后重新读取，操作期间的新按键可能已计数。
    清零保留助手中尚未提交的配置编辑；清零后读回失败不会自动重试清零。
11. Ctrl+5：配对槽位。显示四个槽位的配对状态和名称，以及最近连接的蓝牙槽位。
    当前 USB 连接与最近连接的蓝牙槽位分别显示；无法取得的状态明确显示未知。此页只读，不能清空配对。

导航和退出
Tab / Shift+Tab：移动控件焦点。
Ctrl+Tab / Ctrl+Shift+Tab：切换分区。
Ctrl+1 / Ctrl+2 / Ctrl+3 / Ctrl+4 / Ctrl+5：直接跳到设备状态、逐键设置、自定义快捷键、按键统计、配对槽位。
F5：重新读取设备。存在未保存修改时先提示。
Enter：在按键或快捷键列表中打开编辑。
Escape：取消编辑对话框。
Alt+F4 或“关闭”按钮：退出。助手有未保存编辑时提供“保存并退出、放弃并退出、取消退出”。
保存失败时保留窗口；取消退出或关闭提示框不会丢弃编辑。提示只针对助手编辑，不能判断键盘实体按键的调整是否已永久保存。
设备通信期间 Alt+F4 会请求在当前操作结束后退出。

状态与保存语义
状态摘要中的 APC、ECO、映射配置来自最后一次读取的键盘当前配置，并显示读取时间。
按键详细信息和快捷键列表显示当前编辑值，未保存时有文字提示。
用户实测确认：现有读取字段包含键盘上尚未保存的配置调整，无需另设临时区。
按 F5 可读取调整后的当前配置；本版不自动轮询。未保存的键盘调整在重新拔插后还原为上次保存值。
当前配置读取结果不能判断键盘调整是否已永久保存。“助手中没有待保存的编辑”仅指助手内存中的编辑状态。
用户实测 Fn+F11 首次用于显示当前模式或进入调整状态，短时间内再次按才切换 ECO；随后用 Fn+F12 保存。
APC 键同样需要先按一次显示或进入调整状态，再按一次才切换到下一个模式；连续操作时不要间隔太久。
此前每次只按一次的测试不足以判断读取是否支持临时调整，旧版相应限制提示已撤回。
只读刷新不发送原软件的进入/退出编辑会话命令。
ECO 级别说明取自当前安装版本的资源文本。

保存时会重新读取全部已观察的设置块。如键盘状态已变化，则拒绝覆盖并要求刷新。
写入前会在 %LOCALAPPDATA%\RealforceAccessible\Backups 保存原始块数据和改动清单。
该备份是诊断/恢复数据，本版尚无自动恢复按钮。
只写发生变化的数据块；检查底层错误、每块读回结果、保存命令及保存后的读回结果。
如果部分写入后失败，不会自动重复保存或宣称成功；必须刷新确认实际设备状态。
保存数据读回一致不等同于已经完成断电重连后的持久化测试。

开发文件
src\Program.cs：独立界面、设备适配及离线测试。
resources\key-names.tsv：从本机原程序静态提取的键码名称表。
build.ps1：使用 Windows 自带 .NET Framework 编译器构建到 release。
--probe：只读设备测试，输出到可执行文件同目录的 probe.txt。
--self-test：离线自测，输出到同目录的 self-test.txt，不访问设备。

F1 或关于按钮查看版本与开发者。AnyCPU，64 位 Windows 上以 64 位运行；依赖 .NET Framework 4.8。用户已验证键盘名称修改、保存及重新拔插后的保留。
